# Rapi

소유자에게 맞춘 공개 Discord 봇이다. 놓치기 싫은 것을 알려 준다.
옛 라피(`purple-rapi`, 보관됨)의 배포 기반을 그대로 쓰는 포크이고, 기능은 새로 만든다.

- 앞으로 만들 기능과 정해진 규칙: [ROADMAP.md](ROADMAP.md)
- 지금 버전: 0.0.11. 새 AI API 서비스와 할인 후보를 GitHub, 공식 변경로그, OpenRouter, Hacker News, aifree.dev에서 하루 한 번 찾아 규칙으로 색과 태그를 정하고, 소유자만 보는 채널에 카드로 보낸다. 소유자가 [게시]를 누르고 마감일을 확정하면 다른 채널로 내보내고, [버리기]를 누르면 내보내지 않는다. 허용된 서버의 누구나 `/제보`로 링크를 보낼 수 있고, 문제 제보는 소유자가 빨강으로 정할지 판단한다. 잊고 있던 GitHub 스타는 하루 한두 개 소유자 DM으로 보낸다. 서버마다 켠 기능만 동작하고, 소유자가 `/기능`으로 바꾼다. 승인되지 않은 서버는 `/서버신청`만 쓸 수 있고, 소유자가 카드의 [승인], [차단]과 `/서버`로 정한다.

## 현재 상태

포트: 봇 4000, 모니터 4300, 게이트웨이 4600·4601, 터널 지표 4700, PostgreSQL 5433.
처음 배포하는 절차는 [운영 문서](docs/operations.md#vm에-처음-올리기)에 있다.

## 개발

```sh
npm ci
npm run check     # 포맷, 타입, 린트, 단위 테스트
npm run test:e2e  # Docker 필요
```
