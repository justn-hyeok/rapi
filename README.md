# Redhood

소유자에게 맞춘 공개 Discord 봇이다. 놓치기 싫은 것을 알려 준다.
라피(rapi-agent)의 배포 기반을 그대로 쓰는 포크이고, 기능은 새로 만든다.

- 앞으로 만들 기능과 정해진 규칙: [ROADMAP.md](ROADMAP.md)
- 지금 버전: 0.0.1. 라피와 이름, 서비스, 경로, DB를 나눴고 기능은 아직 비어 있다.

## 현재 상태

라피와 같은 VM에서 돌 수 있게 포트를 옮겼다: 봇 4000, 모니터 4300, 게이트웨이 4600·4601, 터널 지표 4700, PostgreSQL 5433.
처음 배포하는 절차는 [운영 문서](docs/operations.md#vm에-처음-올리기)에 있다.
`docs/`의 운영 문서에는 지운 기능 설명이 남아 있을 수 있다.

## 개발

```sh
npm ci
npm run check     # 포맷, 타입, 린트, 단위 테스트
npm run test:e2e  # Docker 필요
```
